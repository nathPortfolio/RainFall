----------------------------------------------------------------------------------

chunk1: malloc(8)  → eax        (holds tag + pointer)
chunk2: malloc(8)  → eax[1]     (string buffer 1)   ← strcpy(eax[1], argv[1])
chunk3: malloc(8)  → eax_4      (holds tag + pointer)
chunk4: malloc(8)  → eax_4[1]   (string buffer 2)   ← strcpy(eax_4[1], argv[2])

We have a write-what-where primitive:

Overflowing chunk2 (via argv[1]) reaches into chunk3, which holds the pointer eax_4[1] 

If we overwrite eax_4[1] with an address of our choice, then strcpy(eax_4[1], argv[2]) 
will write argv[2] wherever we point it.

----------------------------------------------------------------------------------

chunk2 user data:  8 bytes  (the buffer we want to overflow)
chunk3 header:     8 bytes  (malloc metadata)
chunk3 tag field:  4 bytes  (the *eax_4 = 2)
                  --------
                  20 bytes  → then we hit eax_4[1] (the pointer)
