So we have two mallocs, a strcpy() function that takes av[1] as an argument and 
doesn't check bounds, and a return that calls *eax_1 which is equal to m.
What we want is to overflow av[1] and make that return call n() instead.

Malloc adds a header of 8 bytes to each chunk. That means 8 bytes + size

CHUNK 1:		malloc(0x40) = [8 bytes header][64 bytes user data = buf]
														⎿ strcpy writes here

CHUNK 2:		malloc(4)	 = [8 bytes header][4 bytes = *eax_1]
													⎿ what we'll overwrite

----------------------------------------------------------------------------------

64 bytes of buf + 8 bytes of header = 72 bytes to reach *eax_1 + the address of n()

n() address = 0x8048454
